# opencolibri/starter-fixtures

Castor tasks loading a dataset into the Sylius shop as fixtures (taxons, products, prices and images), without AI or network: `sylius:dataset:list`, `sylius:dataset:load`, `sylius:dataset:unload`.

## Installation

In your Castor project:

```bash
castor composer require opencolibri/starter-fixtures
```

Or install every Colibri Starter package at once with `opencolibri/starter`.

Read the [documentation](https://github.com/opencolibri/colibri-starter/blob/main/docs/datasets/index.md) for usage.
